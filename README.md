# 🖥️ VMware vCenter Inventory Report

Automação para coleta, organização e geração de relatórios de inventário de ambientes VMware vCenter utilizando **PowerShell e VMware PowerCLI**.

## 📌 Objetivo

Este projeto tem como objetivo automatizar o processo de inventário de uma infraestrutura virtualizada VMware, reduzindo a necessidade de coleta manual de informações e facilitando a documentação e análise do ambiente.

A solução consulta o VMware vCenter e consolida informações relevantes da infraestrutura em um relatório estruturado.

## ⚙️ Informações coletadas

A automação permite coletar informações como:

- Hosts VMware ESXi
- Máquinas virtuais
- vCPU e memória RAM
- Discos virtuais
- Datastores
- Redes das máquinas virtuais
- Snapshots
- Informações gerais da infraestrutura

## 🛠️ Tecnologias utilizadas

- PowerShell
- VMware PowerCLI
- VMware vCenter
- VMware ESXi
- Microsoft Excel
- Windows / Linux

## 🔄 Funcionamento

O script conecta-se ao VMware vCenter utilizando o VMware PowerCLI, consulta os objetos da infraestrutura virtual e organiza os dados coletados.

As informações são posteriormente consolidadas em um relatório, permitindo uma visão estruturada do ambiente e facilitando atividades de inventário, documentação e administração da infraestrutura.

## 📊 Aplicações

O relatório pode auxiliar em atividades como:

- Inventário de infraestrutura
- Documentação técnica
- Levantamento de máquinas virtuais
- Análise de recursos computacionais
- Identificação de snapshots
- Levantamento de armazenamento
- Planejamento de capacidade
- Auditorias de infraestrutura

## 🔐 Segurança

Este repositório utiliza apenas exemplos e informações genéricas.

Credenciais, endereços IP, nomes de servidores, domínios e demais informações de ambientes corporativos não são armazenados no código-fonte.
